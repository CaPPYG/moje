Prepojenie Meta Tokenu

Prepojte Instagram Graph API Access Token pre účet @.... Umožní vám to sledovať živé Insights a publikovať fotky a Reely priamo z tohto účtu.

Ak nezadáte, zistíme ho automaticky zavolaním /me cez Meta Graph API.
Požiadavky na token pre postovanie:
1. Účet na Instagrame musí byť Profesionálny / Tvorca (Creator).
2. Token musí obsahovať oprávnenie (scope) instagram_content_publish a instagram_basic.
3. V Meta Developer aplikácii v režime Development musí byť účet pridaný ako Instagram Tester.
